# Raw Data

This folder contains the raw source CSV files used for the Energy Utility Analytics project.

The data was imported into SQL Server and processed through a multi-step ETL workflow.

## Data Pipeline

Raw CSV Files
→ SQL Server Source Tables
→ Data Exploration
→ Data Cleaning
→ Data Transformation
→ ETL / Data Warehouse
→ Power BI

## Source Files

- customers.csv - Customer demographic and contact information
- accounts.csv - Utility customer account information
- account_rate_plans.csv - Account-to-rate-plan relationships
- bills.csv - Customer billing records
- payments.csv - Payment transactions
- energy_usage.csv - Daily energy consumption records
- meters.csv - Utility meter information
- rate_plans.csv - Utility rate plan information
- infrastructure_assets.csv - Utility infrastructure assets
- maintenance_logs.csv - Asset maintenance records
- outages.csv - Utility outage records

## Data Note

The datasets are synthetic and are used solely for demonstration and portfolio purposes.
